Python is different from Java because it does not require semicolons, braces, or explicit type declarations for variables. Python also uses indentation to define blocks of code, while Java uses curly braces. Another difference is that Python code is shorter and easier to read because there is less syntax to write. One bug I encountered was in checking if the average was invalid because I placed the condition after checking if the average was greater than 80. I fixed it by checking first if the average was below 0 or above 100 before assigning the letter grade. This helped me understand that the order of conditions is important in Python.
